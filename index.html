1. Black Hole Click Fix Issue: When focusing on the black hole and clicking it, it was taking you to the career galaxy instead of opening the tesseract. Fix: Moved the black hole click detection outside of the galaxyAlpha > 0.15 condition. Now the black hole click is always detected regardless of the camera position or zoom level. When the black hole is already focused, clicking it will open the tesseract. 2. Galaxy Grid Toggle Issue: The grid toggle didn't reference the current galaxy properly. Fix: Added galaxy association to all line entries in allLines array. Each line now has a galaxy property ('career', 'sentence', 'claude', or null for shared elements). Added updateLineVisibility() function that dims lines from non-focused galaxies while keeping the focused galaxy's lines visible. 3. Right-Click Grid Toggle for Tesseract New Feature: Added a 2D grid view for the tesseract that appears on right-click. This shows all nodes in a grid layout, color-coded by galaxy. Clicking on a card in the grid will close the grid and focus that node in the main view. 4. Connection Line Visual Filters Issue: All connection lines were showing regardless of which galaxy was active, making it disorienting. Fix: Added galaxy property to all line entries Created getGalaxyFromEra() helper function Added updateLineVisibility() function that: Shows all lines when no galaxy is focused When a galaxy is focused, keeps that galaxy's lines at full opacity Dims lines from other galaxies to 15% opacity This function is called automatically when: Focusing on an era (focusEra) Resetting highlights (resetHighlights) Changing galaxy layout mode (setGalaxyLayoutMode)
